# 圆桌

一个让用户亲自主持、多 AI 参与讨论并形成透明阶段纪要的会议原型。

## 本地运行

```bash
npm install
```

运行前在项目根目录创建 `.env.local`：

```bash
AI_MEETING_BASE_URL=https://downstream.jbbtoken.cn/v1
AI_MEETING_API_KEY=你的 API Key
```

然后启动：

```bash
npm run dev
```

也可以直接双击项目根目录的 `启动圆桌.cmd`。它会调用本地 Node.js 启动服务并自动打开浏览器，不需要手动输入启动命令；首次使用前仍需安装一次项目依赖。

当前版本通过本地 Vite 代理调用 OpenAI 兼容 API，API Key 不会发送给浏览器。用户提交议题后，多个模型在互不可见的情况下并行提交并锁定初始观点；会议随后停下来等待用户补充、追问或反对。用户发言后，初始观点和此前记录会向所有议事席公开，各模型在同一轮中并行回应用户、审阅其他席位并说明立场变化。只有用户主动点击后才会形成阶段纪要。

当前尚未实现账户系统、持久化存储和生产环境后端。开发代理只适合本地验证，部署前需要实现独立服务端。
